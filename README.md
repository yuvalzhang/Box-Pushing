# 推箱子游戏

## 项目简介

这是一个基于 Unity 开发的推箱子游戏。项目包含基础推箱子玩法，以及一套基于 `ScriptableObject` 的可视化关卡编辑器，用于配置、校验和持久化关卡数据。

关卡数据与场景表现相互分离，无需直接修改场景即可创建和维护关卡。

## 开发环境

- Unity 版本：2022.3.61f1c1
- 渲染管线：Built-in
- 目标平台：Windows

## 运行方式

1. 使用对应版本的 Unity 打开项目。
2. 打开场景 `Assets/Scenes/MainScene`。
3. 点击 Unity 编辑器顶部的 Play 按钮运行游戏。

## 游戏操作

- 移动：WASD 或方向键
- 重新开始：R
- 撤销：Q
- 返回/退出：Esc

## 关卡编辑器

### 打开与创建关卡

1. 在 Unity 顶部菜单选择 `Level Tools > 关卡编辑器`。
2. 在 Project 窗口中选择 `Create > SO > LevelSO` 创建关卡数据。
3. 将创建的 `LevelSO` 资源拖入编辑器的 `Level SO` 字段。
4. 设置地图尺寸并点击“重置网格数据”，随后即可开始绘制。

> 重置网格数据会清除当前关卡内容，建议在操作前确认数据是否仍需保留。

### 数据分层

关卡采用静态地图层和动态实体层：

| 数值 | 类型   | 所属层 | 说明                     |
| ---- | ------ | ------ | ------------------------ |
| `-1` | 虚无   | 静态层 | 不生成地形               |
| `0`  | 空地   | 静态层 | 玩家和箱子可通行         |
| `1`  | 墙壁   | 静态层 | 不可通行                 |
| `2`  | 目标点 | 静态层 | 用于判断箱子是否到达目标 |
| `3`  | 箱子   | 动态层 | 可被玩家推动             |
| `4`  | 玩家   | 动态层 | 玩家初始位置             |

箱子或玩家位于空地、目标点上时，编辑器会同时显示底层地形和上层实体。

### 编辑功能

- **拖拽绘制**：按住鼠标左键并拖动，可连续绘制当前笔刷。
- **自动补充地面**：在墙壁或虚无格上放置玩家、箱子时，底层会自动转换为空地。
- **分层擦除**：橡皮擦优先移除动态实体，再次擦除才会移除底层地形。
- **撤销操作**：支持编辑器按钮及 Unity 原生 `Ctrl+Z` 撤销。
- **自动保存**：窗口失去焦点时会将当前 `LevelSO` 保存到磁盘。
- **清空地图**：清除全部静态地形和动态实体，执行前会显示确认弹窗。

### 智能墙壁生成

“智能生成紧密包围墙壁”会先移除已有墙壁，再根据所有有效地形和动态实体重新计算墙壁位置。

算法使用八方向邻域扩张，在有效区域周围生成一圈墙壁，并处理对角方向的缺口。若地图为空，则在地图最外围生成一圈墙壁。

> 建议在可游玩区域与地图边界之间预留至少一格空间，避免边缘元素被生成的墙壁覆盖。

### 实时校验

编辑器会在绘制过程中检查以下条件：

- 玩家数量必须为 `1`。
- 箱子和目标点数量必须大于 `0`。
- 箱子数量与目标点数量不一致时显示警告。
- 所有条件满足时，关卡状态显示为可运行。

## 已知问题与后续优化

- 编辑器连续拖拽绘制时会产生较细碎的撤销步数，后续可结合 `Undo.CollapseUndoOperations` 合并单次拖拽的撤销操作组。
- 当前关卡选择界面创建 9 个关卡入口，现有规模下无需额外优化。若后续关卡数量显著增加，可考虑使用对象池复用列表项，并结合循环列表仅创建可视区域内的项目，避免同时创建所有关卡入口。
